Setting up Debugging Tools for Windows - Cheatsheet

Installation

  • Debugging Tools for Windows (x86)
  • Debugging Tools for Windows (AMD64)
  • Debugging Tools for Windows (ARM64)

The 64-bit version can debug 32-bit processes, but it often shows translation layer artifacts; 32-bit Windbg debugging 32-bit processes is cleaner.

Once installed, set the _NT_SYMBOL_PATH environment variable. Add the Windbg installation directory to your PATH.

If ambitious, grab the symbol file and save it somewhere easy to type; you will need its path to load later.

Running the debugger

Run cdb for text mode debugging or windbg for GUI.

  • Run a new process by specifying the target executable and options
  • Attach to an existing process with -p <pid>
  • Running a new process lets you see thread names
  • Use -z <path-to-dump> to examine a minidump
  • Use -o to debug multiple processes with one debugger

Process & Thread Syntax

Process syntax:

|.    Current process
|#    Faulting process
|*    All processes
|<index>  Process at index
|~<pid>   Process by ID

Note: Uses | prefix instead of ~ (thread syntax)

Thread syntax:

~.    Current thread
~#    Faulting thread
~*    All threads
~<index>   Thread at index
~~<tid>   Thread by ID

Note: Uses ~ prefix instead of | (process syntax)

This syntax can be prefixed to restrict scope of certain subcommands:

CommandDescription
fFreeze thread
uThaw thread
sSwitch current thread
~0 bp <address>Set breakpoint to fire only for the main thread

WARNING: Some thread subcommands share abbreviations with regular commands but differ in meaning!

Example: Freeze all threads except main thread

~* f
~0 u

Expression Evaluation

There are three expression evaluators: MASM (default), C++, and NatVis.

NatVis is available only with the dx command.

You can override evaluator per expression with @@masm(...) or @@c++(...).

Immediate evaluation on command line: ? for MASM or ?? for C++. Registers referenced with @.

Example:

?? (@eax + 0n15)

Prints value of eax + 15 (0n prefix is decimal literal)

Examining Data

Old method: dt <module!name> <address>

New (WinDbg 10): dx <C++ expression>

NatVis output uses XML to describe complex data structures for visualization (load with .nvload).

Hypertext output uses debugger markup language for drilling down deep data structures.
