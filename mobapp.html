Mobile Application Penetration Testing Cheat Sheet

This cheat sheet provides a concise collection of high-value information on mobile application penetration testing topics, mapped to the OWASP Mobile Top 10.

📱 Android Application Penetration Testing

Reverse Engineering & Static Analysis

  • APKTool – Reverse engineers Android apps. Decodes resources and rebuilds them post-modification.
    • apktool d <apk file> – Disassemble APK
    • apktool b <modified folder> – Rebuild resources
    • keytool -genkey -v -keystore keys/test.keystore -alias Test -keyalg RSA -keysize 1024 -sigalg SHA1withRSA -validity 10000
    • jarsigner -keystore keys/test.keystore dist/test.apk -sigalg SHA1withRSA -digestalg SHA1 Test
  • Bytecode Viewer – A Java bytecode viewer and decompiler. Fully open-source and lightweight.
  • Jadx – Dex-to-Java decompiler with CLI and GUI options.
  • APK Studio – Qt-based cross-platform IDE for Android reverse engineering.
  • Oat2dex – Converts .oat files to .dex.
    • java -jar oat2dex.jar boot <boot.oat file> – Deoptimize boot classes
    • java -jar oat2dex.jar <app.odex> <boot-class-folder> – Deoptimize app
    • java -jar oat2dex.jar odex <oat file> – Get .odex from .oat
    • java -jar oat2dex.jar smali <oat/odex file> – Get smali from .oat/.odex
  • SpotBugs – Successor of FindBugs; performs static code analysis for Java bugs.
  • Qark – Scans Android source or APKs for security vulnerabilities.
  • SUPER – CLI tool for vulnerability analysis in APKs; decompresses and applies rule sets.
  • AndroBugs – Android vulnerability scanner for static security analysis. No install required.
  • Simplify – De-obfuscates APKs into .dex files for further analysis.
    • simplify.jar -i "input smali files or folder" -o <output dex file>
  • ClassNameDeobfuscator – Parses .smali files from APKTool and extracts .source annotations.
  • Android Backup Extractor – Extracts/rebuilds ADB backups. Useful for app data or APK extraction.
    • adb backup <package name>
    • dd if=backup.ab bs=1 skip=24 | python -c "import zlib,sys;sys.stdout.write(zlib.decompress(sys.stdin.read()))" > backup.tar
  • GDA (GJoy Dex Analyzer) – C++ based Dalvik decompiler for APK, DEX, ODEX, and OAT. Supports JAR, CLASS, and AAR.

Dynamic & Runtime Analysis

  • Cydia Substrate – Enables developers to make changes to existing Android software using injected Substrate extensions.
  • Xposed Framework – Allows runtime modifications to system or app behavior without changing APKs or re-flashing.
  • PID Cat – A colored logcat script that filters output by app-specific processes.
  • Inspeckage – Dynamic analysis tool hooking Android APIs to inspect runtime behavior of apps.
  • Frida – A dynamic instrumentation toolkit for injecting into running processes on Android, iOS, Windows, and macOS.
  • Diff-GUI – Web framework to hook native functions and inject JavaScript using Frida modules.
  • Fridump – Memory dumper based on Frida, works across Android, iOS, and Windows to extract readable memory.
  • House – Frida-powered mobile app analysis GUI for dynamic hooking and scripting.
  • AndBug – Debugger targeting Android’s Dalvik VM.
    • adb shell ps | grep -i "App keyword" – Identify process
    • andbug shell -p <process number> – Attach to process
    • ct <package name> – Trace specific class
    • Debug with jdb:
      • adb forward tcp:<port> jdwp:<port>
      • jdb -attach localhost:<port>
  • Introspy-Android – Blackbox analysis tool for monitoring runtime behavior and security posture of Android apps (built on Cydia Substrate).
  • Drozer – Comprehensive Android security assessment tool.
    • Start session:
      • adb forward tcp:31415 tcp:31415
      • drozer console connect
    • Retrieve package info:
      • run app.package.list -f <app name>
      • run app.package.info -a <package name>
    • Identify attack surface:
      • run app.package.attacksurface <package name>
    • Exploit Activities:
      • run app.activity.info -a <package name> -u
      • run app.activity.start --component <package name> <component name>
    • Exploit Content Providers:
      • run app.provider.info -a <package name>
      • run scanner.provider.finduris -a <package name>
      • run app.provider.query <uri>
      • run app.provider.update <uri> --selection <conditions> <selection arg> <column> <data>
      • run scanner.provider.sqltables -a <package name>
      • run scanner.provider.injection -a <package name>
      • run scanner.provider.traversal -a <package name>
    • Exploit Broadcast Receivers:
      • run app.broadcast.info -a <package name>
      • run app.broadcast.send --component <package name> <component name> --extra <type> <key> <value>
      • run app.broadcast.sniff --action <action>
    • Exploit Services:
      • run app.service.info -a <package name>
      • run app.service.start --action <action> --component <package name> <component name>
      • run app.service.send <package name> <component name> --msg <what> <arg1> <arg2> --extra <type> <key> <value> --bundle-as-obj

Network Analysis and Server Side Testing

  • Tcpdump – A command line packet capture utility.
  • Wireshark – An open-source packet analyzer.
  • Live packet capture example:
    • adb shell "tcpdump -s 0 -w - | nc -l -p 4444"
    • adb forward tcp:4444 tcp:4444
    • nc localhost 4444 | sudo wireshark -k -S -i –
  • Mallory – A Man-in-the-Middle (MiTM) tool for monitoring and manipulating mobile traffic.
  • Burp Suite – Integrated platform for web and mobile app security testing.
  • Installing trusted CA for Android N+ (rooted devices): 
    
openssl x509 -inform PEM -subject_hash -in BurpCA.pem | head -1
cat BurpCA.pem > 9a5ba580.0
openssl x509 -inform PEM -text -in BurpCA.pem -out /dev/null >> 9a5ba580.0
adb root
adb remount
adb push 9a5ba580.0 /system/etc/security/cacerts/
adb shell “chmod 644 /system/etc/security/cacerts/9a5ba580.0”
adb shell “reboot”

    Check: Settings > Security > Trusted Credentials > SYSTEM

  • Burp Suite Mobile Assistant – Facilitates proxying HTTPS traffic on iOS; bypasses SSL pinning for supported apps.
  • OWASP ZAP – Open-source web security scanner for professionals and learners.
  • Proxydroid – Global proxy app for Android.
  • mitmproxy – Interactive, SSL-capable intercepting proxy with console UI.

Bypassing Root Detection and SSL Pinning

  • Magisk – Root solution supporting module system, root hiding, and systemless modifications.
  • Xposed Modules:
    • Just Trust Me – Bypasses SSL certificate pinning.
    • SSLUnpinning – Bypasses SSL certificate validation.
  • Cydia Substrate Modules:
    • Android SSL Trust Killer – Bypasses SSL pinning on most apps.
    • RootCloak Plus – Patches common root detection checks.
  • Android-ssl-bypass – Interactive console tool for bypassing SSL pinning/debugging Android apps.
  • apk-mitm – CLI tool that automatically modifies APKs for HTTPS traffic inspection.
  • Frida CodeShare – Collection of scripts for Frida, shared by global developers.
  • Bypassing Root Detection with Frida:
    • frida --codeshare dzonerzy/fridantiroot -f YOUR_BINARY
  • Bypassing SSL Pinning with Frida:
    • frida --codeshare pcipolloni/universal-android-ssl-pinning-bypass-with-frida -f YOUR_BINARY

Security Libraries

  • PublicKey Pinning – Use a custom X509TrustManager to perform pinning and standard X509 checks.
  • Android Pinning – A standalone library project for certificate pinning.
  • Java AES Crypto – A secure utility for Android string encryption/decryption.
  • ProGuard – Java obfuscator and optimizer.
  • SQLCipher – Open-source extension to SQLite with 256-bit AES encryption.
  • Secure Preferences – Encrypted wrapper for Android SharedPreferences.
  • Trusted Intents – Library for trusted inter-app communication.
  • RootBeer – Lightweight root checker library for Android.
  • Capillary – Library to simplify sending end-to-end encrypted push messages from Java servers to Android clients.
🍏 iOS Application Penetration Testing

Accessing Filesystem

  • Cyberduck, iFunBox, itunnel

Reverse Engineering

  • otool – Displays specified parts of object files or libraries.
  • Clutch – Decrypts the application and dumps the specified bundleID into a binary or .ipa file.
  • Dumpdecrypted – Dumps decrypted Mach-O files from encrypted iPhone apps from memory to disk.
    iPod:~ root# DYLD_INSERT_LIBRARIES=dumpdecrypted.dylib /var/mobile/Applications/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx/Scan.app/Scan
  • class-dump – CLI tool to examine Objective-C runtime info stored in Mach-O files.
  • dsdump – An improved combination of nm and objc/swift class-dump.
  • Weak Classdump – A Cycript script to generate headers for classes, especially when binaries are encrypted.
    iPod:~ root# cycript -p Skype weak_classdump.cy; cycript -p Skype
    #cy weak_classdump_bundle([NSBundle mainBundle],"/tmp/Skype")
  • Fridpa – Automated script for patching IPA files, works on non-jailbroken devices.
  • Frida-iOS-Dump – Pulls decrypted IPA from a jailbroken device.
  • bagbak – Frida-based tool for decrypting iOS apps; supports app extensions, no SSH required.
  • bfinject – Loads arbitrary dylibs into running App Store apps, includes:
    • bash bfinject -P Reddit -L test – A simple test
    • bash bfinject -P Reddit -L decrypt – Decrypt App Store apps
    • bash bfinject -P Reddit -L cycript – Launch Cycript
    Comes bundled with iSpy and Cycript.
  • HopperApp – A reverse engineering tool for OS X and Linux. Supports disassembly, decompiling, and debugging of 32/64-bit executables for Mac, Linux, Windows, and iOS.
  • hopperscripts – Helps demangle Swift function names in HopperApp.
  • Radare2 – Unix-like reverse engineering framework with powerful CLI tools.
  • XReSign – Signs or resigns unencrypted IPA files using a certificate with the corresponding private key. Supports developer, ad-hoc, and enterprise distribution.

Dynamic Analysis

  • cycript – Interactive console combining Objective-C++ and JavaScript to explore and modify running iOS/macOS apps.
    • Show currently visible view controller:
      cy# UIApp.keyWindow.rootViewController.visibleViewController
    • Show view controller at top of navigation stack:
      cy# UIApp.keyWindow.rootViewController.topViewController
    • Get array of objects of a certain class:
      cy# choose(UIViewController)
    • Dump UI (cuts off long descriptions):
      cy# [[UIApp keyWindow] _autolayoutTrace].toString()
    • Skip UIViews and nextResponders to get ViewControllers:
      cy# [[[UIApp keyWindow] rootViewController] _printHierarchy].toString()
    • List methods at runtime:
      cy# classname.messages or use printMethods(className, isa)
    • Print instance variables:
      cy# a=#0x15d0db80
      cy# tryPrintIvars(a)
    • Manipulate properties:
      cy# [a pinCode] or cy# [a setPinCode: @"1234"]
    • Swizzle instance method:
      cy# <classname>.prototype.isValidPin = function(){ return 1; }
    • Swizzle class method:
      cy# Pin.constructor.prototype['isValidPin'] = function(){ return 1; }
  • iNalyzer – AppSec Labs tool for tampering with iOS app methods and parameters.
  • Grapefruit – Runtime instrumentation tool for iOS (formerly Passionfruit).
  • Introspy-iOS – Runtime blackbox analysis tool to understand iOS app behaviors and detect potential security risks.
  • Apple Configurator 2 – Utility to view live system logs from iOS devices.
  • keychaindumper – Dumps available keychain items from jailbroken iOS devices.
  • BinaryCookieReader – Extracts cookies from binary Cookies.binarycookies file.
  • Network Analysis and Server Side Testing
    • Mallory – MiTM tool to monitor and alter mobile app traffic.
    • Burp Suite – Complete suite for web and mobile app penetration testing.
    • OWASP ZAP – Open-source web app vulnerability scanner for beginners and experts.
    • Charles Proxy – HTTP/HTTPS proxy and reverse proxy to inspect and debug traffic.

    Bypassing SSL Pinning & Jailbreak Detection

    • SSL Kill Switch 2 – Blackbox tool to disable SSL certificate validation (including pinning) in iOS and OS X apps.
    • iOS TrustMe – Disables certificate trust checks on iOS devices.
    • tsProtector – Bypasses jailbreak detection.
    • JailProtect – Bypasses jailbreak detection and allows iOS firmware version spoofing.
    • Shadow – Tweak to bypass jailbreak detection by defeating basic detection methods used in many App Store apps.
    • Frida CodeShare – Community-driven collection of Frida scripts that extend Frida's power and support advanced hooking and bypassing tasks.
      • Bypassing SSL Pinning:
        • frida --codeshare lichao890427/ios-ssl-bypass -f YOUR_BINARY
        • frida --codeshare dki/ios10-ssl-bypass -f YOUR_BINARY
    • Security Libraries
      • PublicKey Pinning – Performed via NSURLConnectionDelegate implementing:
        • connection:canAuthenticateAgainstProtectionSpace:
        • connection:didReceiveAuthenticationChallenge:
        • Custom checks use SecTrustEvaluate inside the authentication challenge handler.
      • Swiftshield – Encrypts and obfuscates Swift symbols (including Pods and Storyboards) to protect against reverse engineering tools like class-dump and Cycript.
      • IOSSecuritySuite – Advanced Swift-based platform security and anti-tampering library designed to meet OWASP MASVS (v8) standards.
      • OWASP iMAS – Open-source iOS security controls and tools maintained by the MITRE Corporation, focused on mobile app security best practices.
🔬 Mobile Penetration Testing Labs
  • WaTF Bank – What-a-Terrible-Failure Mobile Banking Application written in Java, Swift 4, Objective-C, and Python (Flask framework). Simulates a real-world mobile banking app with over 30 vulnerabilities based on OWASP Mobile Top 10 Risks.
  • InsecureBankv2 – A vulnerable Android application designed to help security enthusiasts and developers learn Android insecurities. The backend is written in Python.
  • DVIA-v2 – Damn Vulnerable iOS App is intentionally vulnerable, designed for mobile security professionals or students to practice iOS penetration testing legally.
  • DIVA Android – Damn Insecure and Vulnerable App is an Android app built with poor coding practices to teach developers and security professionals about common security flaws.
  • DVHMA – Damn Vulnerable Hybrid Mobile App is an intentionally insecure hybrid mobile app for Android, built to help security professionals test tools and understand hybrid app vulnerabilities.
  • MSTG Hacking Playground – A set of iOS and Android apps designed to be insecure, used to demonstrate vulnerabilities covered in the OWASP Mobile Security Testing Guide (MSTG).
  • UnCrackable Mobile Apps – A series of Android and iOS apps featuring reverse engineering challenges, used throughout the OWASP MSTG for hands-on testing and learning.
  • OWASP iGoat – A learning tool for iOS developers and mobile pentesters, inspired by WebGoat. Helps explore vulnerabilities in iOS apps in a safe environment.
