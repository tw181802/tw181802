Computer Forensics

  • Autopsy®: GUI for The Sleuth Kit® for disk investigation.
  • The Sleuth Kit®: Command line tools for disk image analysis.
  • FTK® (Forensic Toolkit): Fast processing and indexing tool.
  • WinHex: Hex, disk, and RAM editor.
  • X-Ways Forensics: Full-featured forensic suite for Windows.
  • Registry Recon: Recover Windows Registry data.
  • Forensic Explorer™: Advanced sorting, keyword search, and data recovery.

Memory Forensics

  • Volatility: Memory forensics framework for malware and incident analysis.
  • WindowsSCOPE: Reverse engineering and volatile memory analysis.
  • Redline®: Free endpoint tool by FireEye for memory/file inspection.
  • FEX Memory Imager: Free RAM acquisition tool.

Mobile Forensics

  • Mobile Device Investigator®: Logical acquisition of iOS/Android devices.
  • Digital Evidence Investigator® PRO: Combines mobile and computer forensic capabilities.
  • XRY: Logical and physical tools for mobile forensics.
  • Oxygen Forensic Detective: Mobile, IoT, drone, cloud forensics.
  • Magnet ACQUIRE: Cross-platform acquisition tool.

Network Forensics

  • Wireshark: Network protocol analyzer.
  • Network Miner: Passive sniffer and forensic analyzer.
  • Xplico: Open-source NFAT supporting many protocols.
  • F-Response: Remote analysis of networks, RAM, and cloud storage.
