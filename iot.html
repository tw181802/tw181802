Analysis Frameworks

Software tools for analyzing the security of embedded and IoT devices. These frameworks assist in penetration testing, firmware analysis, and much more.

  • EXPLIoT: Pentest framework like Metasploit but specialized for IoT.
  • FACT: The Firmware Analysis and Comparison Tool - Full-featured static analysis framework.
  • FwAnalyzer: Analyze security of firmware based on customized rules, used in DevSecOps.
  • HAL: The Hardware Analyzer - Reverse engineering and manipulation framework for gate-level netlists.
  • HomePWN: Swiss Army Knife for Pentesting of IoT Devices.
  • IoTSecFuzz: Framework for automating IoT layers security analysis.
  • Killerbee: Framework for testing and auditing ZigBee and IEEE 802.15.4 networks.
  • PRET: Printer Exploitation Toolkit.
  • Routersploit: Exploit framework dedicated to embedded devices.

Analysis Tools

These tools allow for the analysis of firmware, binaries, and security vulnerabilities in IoT devices.

  • Binwalk: Extracts files and searches for "interesting" patterns in firmware.
  • cwe_checker: Finds vulnerable patterns in binary executables (ELF support for multiple architectures).
  • Ghidra: Software reverse engineering suite for arbitrary binaries.
  • Radare2: A framework for software reverse engineering with an extensive command-line toolset.
  • Trommel: Searches extracted firmware images for interesting files and information.

Extraction Tools

Tools for extracting and manipulating firmware from IoT devices for further analysis.

  • FACT Extractor: Detects container formats and executes the corresponding extraction tool.
  • Firmware Mod Kit: Extraction tools for various container formats.
  • SRecord package: Collection of tools for manipulating EPROM files.

Hardware Tools

Hardware tools for interacting with embedded devices, debug ports, and security testing.

  • Bus Blaster: Detects and interacts with hardware debug ports like UART and JTAG.
  • Saleae: Logic analyzer that supports many protocols.
  • ChipWhisperer: Detects glitch/side-channel attacks.
  • J-Link: USB-powered JTAG debug probes for multiple CPU cores.

Bluetooth BLE Tools

Tools to help with the analysis and security testing of Bluetooth Low Energy devices.

  • UberTooth One: Open-source platform for Bluetooth experimentation.
  • Bluefruit LE Sniffer: Bluetooth Low Energy sniffer tool for easy usage.

ZigBee Tools

Security research and debugging tools for ZigBee networks and IEEE 802.15.4 systems.

  • ApiMote: ZigBee security research hardware compatible with Killerbee.
  • Atmel RZUSBstick: Tool for development and debugging ZigBee networks.
  • Freakduino: Low-cost, battery-operated wireless Arduino board for IEEE 802.15.4 sniffer.

SDR Tools

Software Defined Radio tools for radio frequency experimentation and analysis.

  • RTL-SDR: Cheapest SDR for beginners, great for receiving live radio signals.
  • HackRF One: SDR capable of transmission or reception of signals from 1 MHz to 6 GHz.
  • YardStick One: Half-duplex sub-1 GHz wireless transceiver.

RFID NFC Tools

Tools for working with RFID and NFC tags and devices for security testing.

  • Proxmark 3 RDV4: Powerful RFID tool for 125kHz to 13.56MHz tags.
  • ChamaleonMini: Portable tool for NFC security analysis.
  • HydraNFC: Powerful RFID/NFC platform for cracking and sniffing.
