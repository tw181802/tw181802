WinDbg Commands Reference

Thread Control & TEB

~* k                Call stack for all threads
~2 f               Freeze thread TID=2
~# f               Freeze thread causing current exception
~3 u               Unfreeze thread TID=3
~2e r; k; kd       Equivalent of ~2r; ~2k; ~2kd
~*e !gle           Run !gle on all threads
!tls -1            Dump all TLS slots for current thread
!runaway 7         Show time usage by thread
!teb               Dump current thread's TEB
dt ntdll!_TEB @$teb Dump detailed TEB of current thread

Breakpoints

Basic Breakpoint Commands 
bl                  List breakpoints
bc *                Clear all breakpoints
bd #                Disable breakpoint #
be #                Enable breakpoint #
bp Addr             Set breakpoint at address
bu Sym              Unresolved breakpoint (on load)
bm Pattern          Symbolic breakpoint with pattern
ba w4 Addr          Break on memory write access
Breakpoint Examples 
bp mod!source.c:12                    Breakpoint at source line
bm myprogram!mem*                    Wildcard symbol breakpoint
bu myModule!func                     Breakpoint on module load
bp @@( MyClass::MyMethod )           Break on overloaded method
bp mod!addr /1                       Trigger only once
bp mod!addr k                        Trigger after k-1 passes
ba w4 81a578a8 "k;g"                 Log + continue
bu myModule!func ".dump c:\dump.dmp; g"
bu kernel32!LoadLibraryExW ".echo DLL Load ->; du dwo(@esp+4); g"
Skip Execution Example 
bu sioctl!DriverEntry "r eip = poi(@esp); r esp = @esp + 0xC; .echo skipped; g"
bu MyApp!WinMain "r eip = poi(@esp); r esp = @esp + 0x14; .echo entered; g"
Programmatic Breakpoints 
kernel32!DebugBreak
ntdll!DbgBreakPoint
__asm int 3  // x86 only

Tracing & Stepping (F10, F11)

Basic Execution Control 
g       Continue execution
gu      Run until function returns (go up)
p       Step over (source or asm)
t       Step into
pt      Step until return (in current context)
tt      Trace until return
pc      Step until call
tc      Trace until call
pa Addr Step until address
ta Addr Trace until address
Watch & Trace (wt command) 
wt                      Trace and log function calls
wt -l 3                 Max call depth 3
wt -m kernel32          Only trace kernel32
wt -oa                  Show actual call addresses
wt -or                  Show return register values
Step Filters 
.step_filter             Show current filters
.step_filter "Func1;Func2"  Add filters
.step_filter /c          Clear filters

Execution Control

  • g — go
  • g `:123`; ? poi(counter); g — go to line 123, print counter, resume
  • p — single step
  • pr — toggle register display
  • p 5 "kb" — step 5 times, then run kb
  • pc — step to next CALL
  • pa 7c801b0b — step until address 7c801b0b
  • wt — trace and watch sub-functions
  • wt -l 4 -oR — trace depth 4, show return values

Call Stack

  • k — display call stack
  • kn — with frame numbers
  • kb — show 3 params
  • kb 5 — show 5 frames
  • kd — dump raw stack
  • kM — DML variant with links
  • .kframes — set stack length (default 20)
  • .frame — show/set frame, display registers
  • !uniqstack — stacks for all threads
  • !findstack Symbol — locate stacks containing a symbol

Registers

  • r — show all or specific registers
  • r eax=5 — set register value
  • r eax:uw — display in specific format
  • rM 0x1 — integer registers
  • rF — floating-point registers
  • rX — SSE XMM registers
  • rm ? — show register masks

Variables

  • dt — dump type info
  • dt ntdll!_PEB — dump PEB
  • dv — display local variables
  • dv /t /i /V — type, scope, memory info

Memory

  • dd, du, dc, etc. — display memory
  • e* — edit memory
  • ds, dS — dump string struct
  • dd*, dq*, dp* — dereference pointers
  • dl — display linked list
  • !address — display memory regions
  • !mapped_file — show mapped file for address

Memory Operations

  • c — compare memory
  • m — move memory
  • f — fill memory
  • s — search memory
  • .holdmem — hold & compare memory snapshots

Heap Analysis

  • !heap — heap overview
  • !heap -p -a Addr — show heap block and call stack
  • !heap -stat — heap statistics
  • !heap -flt s Size — allocations of a specific size
  • !heap -p -all — show all allocations

Application Verifier

  • !avrf — show verifier info
  • !avrf -vs N — virtual space log
  • !avrf -hp N — heap log
  • !avrf -dlls N — DLL load/unload log
  • !avrf -trace INDEX — trace details

Logging (logexts.dll)

  • !loge — enable logging
  • !logd — disable logging
  • !logo — configure output
  • !logc — category control
  • !logm — module filter
  • !logb — print or flush log buffer
