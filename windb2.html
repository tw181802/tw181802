WinDbg Cheat Sheet (User Mode Only)

Help Commands 

?         Help on Debugee commands
.help     Help on Debugger commands
.hh cmd   Open WinDbg’s help for this command
Execution Control 

restart         Stop and restart execution
t (F11)         Step into (trace)
p [count] (F10) Step over
pa address      Run to address
pt              Execute until a return instruction is reached
ph [count]      Execute until a branching instruction is reached
g (F5)          Continue (go)
gu (Shift-F11)  Execute until current function complete
Ctrl-Break      Break
Breakpoints 

bl                  List breakpoints
bp [addr] ["script"] Set breakpoint at addr and optional script
bp                   Set breakpoint at current instruction
bu symbol            Set unresolved breakpoint on symbol
bm pattern           Set breakpoint on all symbols matching pattern
bc # / *             Clear breakpoint # or all
bd # / *             Disable breakpoint # or all
be # / *             Enable breakpoint # or all
ba [access] [size] addr  Break on memory access
  access: r=read, w=write, e=execute
  size: 1,2 or 4 bytes
Listing Modules 

lm [olfv]     List modules
lm o          Loaded modules only
lm l          Modules with symbol info
lm f          All modules with full image path
lm v          Verbose listing
lm a address  Module containing address
lm m pattern  Find module name (wildcard supported)
lm M pattern  Find image path (wildcard supported)
Symbols 

.reload /f       Reload all symbols
ld module       Load symbols for module
ld *            Load symbols for all modules
ln address      Find nearest symbol to address
x module!symbol Display symbols matching pattern
Registers 

r               Display all registers and values
r reg           Display specific register value
r reg=value     Set register to value
Unassembly 

u[ub] address [L#] Unassemble from memory
uu address       Continue disassembly past read error
ub address       Disassemble backwards from address
u address L#    Disassemble # instructions from address
Display Memory 

d{type} [/c#] addr [L#] Display memory contents
Types:
b = Bytes + ASCII chars
w = WORD (2 bytes)
W = WORD + ASCII chars
d = DWORD (4 bytes)
c = DWORD + ASCII chars
q = QWORD (8 bytes)
a = ASCII string
u = Unicode string
f = Float (4 bytes)
D = Double (8 bytes)
d* /c# addr     Set columns
d* addr L#      Set length
Searching Memory 

s -[type] range pattern   Search memory range
Types:
b = Byte
w = WORD
d = DWORD
q = QWORD
a = ASCII string
u = Unicode string

Example:
s -a 0 L?80000000 "string"
s -d 0 L?80000000 41414141
Display Type Information 

dt [-r] name              Display variable or type info
dt -r name                Recursively dump subtype fields
dt name addr              Specify address of struct
dt ntdll!_TEB @$teb       Use @ to specify register
dt name field             Display specific field
Display Memory & Symbols 

dds range   Display DWORD values & symbols
dqs range   Display QWORD values & symbols
dps range   Display pointer-sized values & symbols
Evaluate Expressions 

? expr      Evaluate expression
?? expr     Evaluate C++ expression
.formats expr  Show multiple formats

Examples:
? 77269bc0 - 77231430
? 77269bc0 >> 18
? 41 (decimal)
?? sizeof(ntdll!_TEB)
Prefixes 

0x Hexadecimal (default)
0n Decimal
0y Binary
Miscellaneous 

k[bpPv]   Display stack backtrace
a [addr]  Assemble x86 instructions into memory at address
Extensions 

!address [addr]     Display memory map
!exchain            Display current exception handler chain
!vprot addr         Display virtual memory protection info
!dh addr            Display image headers
