Privacy Policy

Last Updated: July 16, 2026

Ticket Queue Alert ("the Extension") is designed to notify users when new tickets appear in a supported ticket queue. Your privacy is important, and this Privacy Policy explains what information the Extension accesses and how that information is used.

Information We Collect

The Extension does not collect, store, transmit, or sell personal information.

The Extension only accesses the content of supported ticket queue webpages necessary to determine whether new tickets are available.

How Information Is Used

Information accessed from the ticket queue is used solely to:

  • Detect when new tickets appear.
  • Display browser notifications.
  • Play an alert sound when configured.
  • Maintain user preferences stored locally.

The Extension does not transmit ticket information to any external servers.

Data Storage

User preferences, such as notification settings and monitoring options, are stored locally using Chrome's storage API. These settings remain on your device unless you remove the Extension or clear browser data.

Data Sharing

Ticket Queue Alert does not:

  • Sell user data.
  • Share user data with third parties.
  • Use user data for advertising.
  • Use user data for analytics or tracking.

Permissions

The Extension requests only the permissions required for its functionality:

  • Storage – Saves user preferences locally.
  • Notifications – Displays alerts when new tickets are detected.
  • Host Permissions – Allows the Extension to monitor supported ticket queue webpages.
  • Scripting / Active Tab – Enables the Extension to interact with supported webpages when necessary.

Remote Code

The Extension does not download or execute remote JavaScript or WebAssembly. All executable code is packaged with the Extension.

Third-Party Services

The Extension does not use third-party analytics, advertising, tracking services, or external data collection services.

Children's Privacy

The Extension is not intended for children under the age of 13 and does not knowingly collect personal information from children.

Changes to This Policy

This Privacy Policy may be updated from time to time. Any changes will be posted on this page with an updated revision date.

Contact

If you have questions regarding this Privacy Policy, please contact the developer through the Chrome Web Store listing or your organization's support channel.
