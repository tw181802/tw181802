Privacy Policy

Effective Date: 06/23/2025

Extension Name: Infin1teX Auto Refresh

1. Introduction

This Chrome extension was created to automatically refresh your active browser tab at a specified interval. We respect your privacy and are committed to protecting it. This policy explains our data practices.

2. Data Collection

We do not collect, store, or transmit any personal or sensitive user data of any kind. This includes:

  • No collection of browser history
  • No tracking of user activity
  • No use of cookies or local storage
  • No logging or analytics

3. Data Sharing

Since we do not collect any user data, there is nothing to share. We do not and will not share, sell, rent, or disclose user data to any third party — for any reason.

4. Permissions

This extension uses only the minimum permissions required to function:

  • tabs: To access and refresh the active tab
  • scripting: To run the refresh logic on the current tab

These permissions are used strictly to provide the auto-refresh functionality and do not access, modify, or log any content from the websites you visit.

5. Security

As this extension does not handle or store any user data, no special security measures are needed. However, we follow best practices in secure coding and Chrome extension development.

6. Changes to this Policy

If this privacy policy is ever updated, we will post those changes on this page. This extension will never begin collecting data without first updating this policy and obtaining clear user consent.

Summary

We do not collect, track, store, or transmit any user data. Your privacy is completely respected.
